Linux Architecture
-----
Linux architecture is based on ASK
A = Application
S = Shell command interpreter between user and kernel
K = kernel core component of Linux
Hardware ----> Kernel ------> Shell ------> Application

Linux process 
-----
In Linux, a process is simply an instance of a program in execution. 
Every time you run a command or start a service (like Nginx), the system creates a process that is assigned a unique Process ID (PID)

systemd
---
systemd is the "mother of all processes." It is the first process that starts when you boot up (PID 1) and acts as a system and service manager.
